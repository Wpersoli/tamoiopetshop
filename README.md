## Implementação
Static HTML/CSS/JS. GitHub → Vercel. Sem build, sem framework, sem chaves, sem custo obrigatório para demonstração.
- Responsivo e acessível: navegação com teclado, menu mobile, focus styles, reduced-motion, HTML semântico.
- Carrossel com setas, toque, rolagem, indicadores, pausa e autoplay com controle de visibilidade.
- Assistente local inteligente de respostas por assuntos, com encaminhamento de histórico da pergunta para WhatsApp; **não é IA conectada a modelo externo**.
- Leaflet/OpenStreetMap + marcador aproximado, permissão de geolocalização e rotas OSRM para carro quando disponíveis; modos a pé/bicicleta abrem Google Maps. Distâncias/tempos calculados são **estimativas sem trânsito em tempo real**.
- FAQ accordion nativo, compartilhamento do link, botões WhatsApp por serviço, barra fixa mobile após hero.
- Política de privacidade DEMONSTRATIVA; formulário de inscrição e automação de e-mail não ativados (não há backend).
- Demonstração protegida contra indexação via meta/headers/robots.txt. Na entrega aprovada pelo cliente, revisar e remover estas restrições conforme orientação do responsável.
